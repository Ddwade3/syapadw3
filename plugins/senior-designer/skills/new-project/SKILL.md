# Новый проект: $ARGUMENTS

Это одноразовая процедура для пустой или почти пустой папки проекта. Не запускать в папке, где уже есть заполненный `CLAUDE.md` — вместо этого предложить дополнить его.

## 1. Папки и файлы
Создать (если нет):
```
brief/            ← ТЗ, прототип, бренд-бук
brief/refs/       ← референсы, мудборд, скриншоты
assets/           ← картинки для макета (в т.ч. из ChatGPT)
qa/               ← PNG-экспорты и JSON-отчёты проверок
CLAUDE.md         ← из ${CLAUDE_PLUGIN_ROOT}/../../templates/CLAUDE.md (если путь недоступен — Glob **/senior-designer/**/templates/CLAUDE.md или ниже структура)
design-notes.md   ← из templates/design-notes.md
```
Если шаблоны не найдены — создать файлы по структуре: Роли · Бриф · Утверждённые токены · Утверждённые секции · Картинки · Текущая задача · Правила проекта; и журнал с разделами «Забраковано / Утверждено / Открытые вопросы».

## 2. Собрать материалы
Спросить у арт-директора одним сообщением: ТЗ (файл/текст), прототип/скелет, мудборд и референсы (файлы или ссылка на Figma-файл с референсами), бренд-бук/шрифты/цвета клиента, целевое устройство (десктоп/мобильный/оба), главное действие на странице. Всё, что прислано файлами, положить в `brief/`.

## 3. Бриф в CLAUDE.md
Заполнить раздел «Бриф» конкретикой (см. шаг 1 скилла `design`): аудитория, задача, CTA, тон (3 прилагательных с привязкой к референсам), что именно нравится в каждом референсе, ограничения. Показать арт-директору на подтверждение — это 10 строк, не документ.

## 4. Токены
По `references/typography.md` и `references/rules.md` скилла `design` предложить: палитру (с проверенным контрастом), 2 типографические пары, шкалу, отступы, радиусы, тени, набор иконок. Показать на одном фрейме «Foundations» в Figma: образцы цвета с подписью контраста, заголовок + абзац из ТЗ в обеих парах, шкала отступов. После выбора — записать в CLAUDE.md.

## 5. UI-кит в Figma
Создать страницу «UI Kit»: переменные (цвета с scopes, отступы, радиусы), текстовые стили, эффекты; компоненты: Button (primary/secondary/tertiary × default/hover/focus/disabled × 2 размера), Input (default/focus/error/disabled, с подписью и ошибкой), Card (базовая), Nav (десктоп/моб), Section-контейнер. Вернуть id и записать ссылку в CLAUDE.md.

## 6. Финал
Сообщить одной строкой, что готово, и предложить начать с первой секции через процесс `design` (шаг 2). Дальше арт-директор говорит «делаем герой» — и работа идёт по процессу.
