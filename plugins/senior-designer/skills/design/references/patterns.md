# Паттерны секций и компонентов (2025–2026)

Каждый блок сайта решает одну задачу пользователя. Сначала называется задача, потом выбирается паттерн, потом — стиль. Если паттерн выбирается по вкусу «так красивее» без задачи — это и есть велосипед.

Перед сборкой любой секции обязательна проверка по реальным примерам: Mobbin (`search_sections` для сайтов, `search_screens`/`search_flows` для приложений) — 5–8 примеров, из них выбираются 2–3 опорных. Не копировать, а брать структуру.

## Герой (первый экран)

Задача: за 5 секунд ответить «что это», «для кого», «что сделать». Один заголовок, один лид (≤ 2 строк), одна главная кнопка, не больше одной второстепенной. Выше сгиба на 1440×900 должны поместиться заголовок, лид и кнопка.

| Вариант | Когда | Структура |
|---|---|---|
| Split (текст слева, продукт/фото справа) | есть что показать: продукт, интерфейс, объект | 6/6 или 5/7 колонок; на мобильном текст сверху |
| Product-led | SaaS, приложение | заголовок + кнопка по центру, под ними крупный интерфейс/мокап на всю ширину контейнера |
| Editorial (крупная типографика) | агентства, бренды, премиум | дисплейный заголовок 72–120px на 8–10 колонок, фото ниже или сбоку малым |
| Full-bleed фото/видео | авто, outdoor, недвижимость — эмоция важнее | затемнение 40–60% под текстом или текст на цветной подложке; текст слева, не по центру |
| Форма в герое | лидогенерация с одним действием (расчёт, запись) | текст слева 6–7 колонок, форма справа 4–5 колонок, ≤ 3 поля |
| Bento-hero | продукт с 4–6 сильными фактами | заголовок + плитки разного размера, каждая с одним фактом |

Герой не должен содержать: три кнопки, два абзаца, слайдер, бегущую строку, 4 бейджа «№1».

## Навигация

- Десктоп: логотип слева, 4–6 пунктов, справа одна главная кнопка (и, если нужно, телефон/вход). Высота 64–80. Прилипает при скролле с уменьшением до 56–64 и полупрозрачным фоном.
- Мега-меню — только при ≥ 8 разделов с подразделами; открывается по клику/ховеру с задержкой.
- Мобильный: логотип + кнопка + бургер; меню открывается полноэкранной панелью с крупными пунктами (≥ 20px, высота строки 48–56).
- Текущая страница/раздел выделен.

## Преимущества / фичи

- Не «ряд из трёх иконок». Сначала решить: это **список фактов** (цифры, спецификации) → таблица/плитки с цифрами; **объяснение механизма** → шаги с картинками; **сравнение** → таблица «было/стало»; **разнородные факты** → бенто 5–8 плиток.
- Каждый элемент — один тезис: заголовок 3–6 слов + 1–2 строки. Если нужно 3 абзаца — это другая секция.
- Иконки: один набор, одна толщина линии (1.5–2px при 24px), в контейнере 40–48, либо без иконок вовсе.
- Чередование «текст слева / картинка справа» (zig-zag) — только для 2–3 крупных фич с реальными изображениями; по айтрекингу NN/g зигзаг сканируется хуже, чем вертикально выровненные ряды, поэтому при 4+ фичах — текст всегда с одной стороны, самое информативное — слева в первом ряду, текст выровнен по верху картинки.

## Карточки

- Карточка нужна, когда элементы равноправны и их можно сравнивать (товары, тарифы, кейсы). Для текста — не нужна.
- Внутри: изображение/иконка → заголовок → описание → мета (цена, срок) → действие. Отступ 16–24, один радиус на проект (8/12/16; 24+ только для крупных).
- Граница 1px или тень — не оба. Hover: смена фона/границы, подъём ≤ 2–4px (не 12).
- В ряду 3–4 на десктопе, 2 на планшете, 1 на мобильном (или горизонтальный скролл с видимым «хвостом» следующей карточки).
- Выравнивание содержимого по верху и по сетке между карточками: заголовки на одной линии, кнопки прижаты к низу.

## Социальное доказательство

- Логотипы клиентов: 5–8 в один ряд, монохром, одна высота (24–32), с подписью «нам доверяют» только если это правда.
- Отзывы: фото + имя + должность/город + 2–4 строки конкретного результата. Один отзыв крупно сильнее трёх мелких. Без «звёздочек» 5/5 ради звёздочек.
- Цифры: 3–4 показателя, каждый с единицей и контекстом («1 200 машин в месяц», не «1200+»).
- Кейсы: до/после или задача → решение → результат.

## Тарифы

- 2–4 колонки, рекомендуемый тариф выделен (граница/фон/метка), но не «кричит».
- Цена крупно (32–48), период рядом мелко, список включённого 5–8 пунктов с одинаковыми отметками, кнопка в каждой колонке внизу на одной линии.
- Переключатель месяц/год — сегмент, не чекбокс.
- Сравнение по функциям — отдельная таблица ниже, не в карточках.

## Как это работает / шаги

- 3–5 шагов, нумерация уместна (это последовательность). Горизонтально на десктопе, вертикально на мобильном. У каждого шага глагол в заголовке.

## FAQ

- Аккордеон, 5–8 вопросов, вопрос — как его задаёт клиент, ответ ≤ 4 строк. Первый пункт может быть раскрыт.

## CTA-секция (предпоследняя)

- Один заголовок-призыв, одна кнопка, при необходимости — телефон/мессенджер как вторичное. Контрастный фон по отношению к соседям.

## Футер

- 3–4 колонки ссылок + контакты + соцсети + юридическая строка. Контраст ссылок ≥ 4.5:1 даже на тёмном фоне. На мобильном — аккордеоны или один столбец.

## Формы и лидогенерация

- См. rules.md §6. Для расчётов/записи: шаговая форма (2–3 шага) с индикатором лучше, чем 8 полей сразу.
- Согласие на обработку данных — чекбокс с ссылкой, текст ≥ 12px и ≥ 4.5:1.
- После отправки — экран «что дальше» (когда перезвоним), не «Спасибо».

## Мобильная версия

- Mobile-first по структуре: порядок блоков на мобильном — это истинный порядок важности.
- Всё в одну колонку, поля 16–20, секции 64–96, кнопки на всю ширину контейнера (или min 44 высота).
- Таблицы → карточки или горизонтальный скролл с тенью-подсказкой.
- Липкая CTA-полоса внизу для лендингов с одним действием.

## Стилевые тренды — с условиями

| Тренд | Работает, когда | Ломается, когда |
|---|---|---|
| Bento | 5–8 фактов одного веса, разной формы контента | плитки заполняются «чтобы было», одинаковые карточки |
| Крупная типографика | есть сильная короткая фраза и воздух | фраза длинная или банальная |
| Glassmorphism | один слой над насыщенным фоном/фото | светлый фон, много слоёв, текст внутри |
| Тёмная тема | продукт/техника/вечерний сценарий, строгий контраст | весь текст серым на чёрном, тонкие шрифты |
| Градиенты | 2 близких тона, как фон или акцент | 3+ цвета, «блобы», градиент на тексте |
| Микро-анимация | одна оркестрованная при загрузке + ответы на действия | всё плывёт на каждом скролле |
| Реальная съёмка / продукт | всегда лучше стока | нет бюджета → типографика и интерфейс, не сток |

## Чего ждёт арт-директор от первого показа

1. Секция собрана по сетке, на токенах, с автолейаутом.
2. Один паттерн выбран по задаче и назван («split-hero, потому что есть продукт для показа»).
3. Текст — реальный из ТЗ или осмысленная заглушка по теме, не lorem ipsum и не «Заголовок».
4. Проверка QA-скриптом и критиком пройдена: FAIL — 0.
5. К варианту одна строка: что это за направление и чем отличается от других.
