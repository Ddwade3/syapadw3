# Чек-лист приёмки (перед любым показом арт-директору)

Проходится дважды: сначала автоматически (`scripts/figma-qa.js`), потом критиком (`design-critic`) по скриншоту. Любой FAIL — вариант не показывается, а исправляется. WARN — исправляется, если это не осознанное решение, которое названо в комментарии к варианту.

## A. Структура и сетка

- [ ] Секция — один фрейм нужной ширины (1440 десктоп / 390 мобильный), внутри контент-контейнер по сетке (12 / 4 колонки).
- [ ] Все контейнеры с ≥ 2 детьми — auto layout. Абсолютное позиционирование только у декоративных слоёв с `/abs` в имени.
- [ ] Ничего не выходит за фрейм, ничего не обрезано, ничего не «почти по колонке».
- [ ] Текст не касается границ карточек/кнопок/фрейма.
- [ ] Порядок слоёв = порядок чтения.

## B. Наложения и отступы

- [ ] Нет пересечений текста с текстом. (FAIL)
- [ ] Нет пересечений элементов, кроме осознанных наложений (бейдж на фото, карточка поверх героя) — и те названы.
- [ ] Все отступы из шкалы 4/8: 4 8 12 16 20 24 32 40 48 64 80 96 128 160.
- [ ] Внутри группы < между группами < между секциями.
- [ ] Между секциями на десктопе ≥ 96.

## C. Типографика

- [ ] ≤ 2 гарнитуры, одна шкала размеров; в секции ≤ 4 размеров.
- [ ] Основной текст ≥ 16px, минимум где-либо ≥ 12px.
- [ ] Межстрочное: текст 1.4–1.6, заголовки 1.1–1.25.
- [ ] Строка ≤ 75 символов.
- [ ] Выравнивание по левому краю; центр только для коротких заголовков.
- [ ] Нет висячих предлогов, «ёлочки» и тире на месте.
- [ ] Нет lorem ipsum, нет «Заголовок»/«Текст», нет текста, не относящегося к проекту.

## D. Цвет и контраст

- [ ] Весь текст ≥ 4.5:1 (крупный ≥ 3:1) к реальному фону; на фото/градиенте — проверено в худшей точке.
- [ ] Иконки, границы полей, фокус ≥ 3:1.
- [ ] Цвета только из палитры проекта (стили/переменные), случайных hex нет.
- [ ] Один акцентный цвет для действий; он не используется для декора рядом.
- [ ] Цвет не единственный носитель смысла.

## E. Иерархия и смысл

- [ ] Тест на прищур: 1 главное пятно, 1 действие.
- [ ] Одна primary-кнопка в секции; остальные secondary/tertiary.
- [ ] Каждый элемент несёт один тезис; информация не повторяется в соседних блоках.
- [ ] Паттерн выбран по задаче пользователя и назван; есть 2–3 опорных примера из Mobbin.
- [ ] Заголовок отвечает «что это и зачем мне», лид ≤ 2 строк.
- [ ] Нет перегруза: если убрать любой элемент и смысл не пострадает — убрать.

## F. Интерактив

- [ ] Кнопки 44–48 высотой, цели касания ≥ 44×44 (моб.) / ≥ 24×24 (деск.), между целями ≥ 8.
- [ ] Для кнопок и полей есть hover + focus (в UI-ките).
- [ ] Поля: подпись над полем, высота 44–56, ошибка под полем с инструкцией.
- [ ] Кнопка названа глаголом результата.

## G. Анти-паттерны

- [ ] Нет пунктов из anti-patterns.md §1 (AI-вид), кроме прямо затребованных брифом.
- [ ] Нет устаревших паттернов из anti-patterns.md §2.
- [ ] Нет пунктов из `design-notes.md` проекта (то, что арт-директор уже браковал).

## H. Figma-гигиена

- [ ] Имена слоёв осмысленные, без `Frame 123`.
- [ ] Стили/переменные привязаны; в компонентах нет хардкода.
- [ ] Повторяющиеся элементы — инстансы компонентов.
- [ ] Текстовые блоки с фиксированной шириной и авто-высотой.

## I. Картинки из ChatGPT

- [ ] Соответствуют теме и стилю проекта (не «пластик», не абстрактные блобы, нет лишних пальцев/букв).
- [ ] Разрешение ≥ 2× размера контейнера.
- [ ] Стиль одинаковый у всех картинок на странице (одно освещение, один ракурс, одна палитра).
- [ ] Картинка не единственный носитель смысла — рядом есть текст.

## Форма отчёта критика

```
VERDICT: PASS | FAIL
FAIL:
- [B] Заголовок «…» пересекает карточку «…» (узлы 12:34, 12:40). Исправить: …
- [D] Текст #8A8A8A на #FFFFFF = 3.2:1. Нужно ≥ 4.5:1 → #6B6B6B.
WARN:
- [E] Две primary-кнопки в герое. Вторую — secondary.
OK:
- сетка, типографика, паттерн
ONE LINE FOR ART DIRECTOR: «Split-hero с продуктом справа, спокойная пара Manrope/Inter; отличие от варианта B — …»
```
