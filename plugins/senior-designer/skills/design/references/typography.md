# Типографика: выбор и настройка

## Как выбирать гарнитуру (порядок)

1. **Что сказано в брифе и референсах** — выполняется буквально. Если клиент прислал шрифт или бренд-бук — используется он, без обсуждения.
2. **Характер ниши и аудитории** → таблица ниже. Шрифт несёт тон: один и тот же лендинг на Golos читается как «спокойный сервис», на Lora + Cormorant — как «редакция/премиум», на Unbounded — как «молодой бренд».
3. **Кириллица обязательна и проверена.** Русский текст на шрифте с плохой кириллицей (кривые «Д», «Ж», «Л», «б», узкая «Ф») — брак, который заметит клиент. Единственный независимый экспертный источник по кириллице в Google Fonts — обзоры type.today; их вердикты в таблице. Шрифт без вердикта = проверить глазом на заголовке с «Дж», «Ф», «Л», «б», «ы».
4. **Технические требования:** переменный шрифт (один файл, все начертания), лицензия (Google Fonts = бесплатно для коммерческого использования), наличие начертаний 400/500/600/700 минимум, для русского — субсеты `cyrillic` и желательно `cyrillic-ext`.
5. Предложить арт-директору **2 пары**, а не одну: «вариант А (спокойнее) / вариант Б (характернее)», показать на реальном заголовке и абзаце из ТЗ.
6. **Inter везде** — уже примета шаблонного AI-дизайна (несколько обзоров 2026 года), а его кириллица type.today не рекомендует. Inter — только если его требует бриф или продукт уже на нём.

### Особенности финтеха (Smashing Magazine, 2023)
- Низкоконтрастный гротеск для текста; различимые i/l/I; открытые апертуры, крупные внутрибуквенные просветы, большая x-высота; не узкие гарнитуры.
- Одно суперсемейство (Sans + Mono) — «идеальное рабочее решение».
- Табличные цифры (tnum) для колонок и меняющихся значений; код валюты после числа.
- 3–5 уровней заголовков; без капса, курсива и подчёркивания в заголовках.
- В плотных продуктовых интерфейсах (трейдинг, таблицы) текст 12–16px допустим при межстрочном 120–145% и 55–60 символах в строке; для лендингов остаётся 16+.

## Настройка (значения по умолчанию, пока бриф не требует иного)

```
Шкала 1.25 от 16 (лендинг, десктоп):
display   64–80 / lh 1.0–1.05 / tracking −1…−2% по глазу
h1        48–56 / lh 1.1
h2        36–40 / lh 1.15
h3        24–28 / lh 1.25
lead      20    / lh 1.5
body      16–18 / lh 1.5–1.6
small     14    / lh 1.45
caption   12–13 / lh 1.4 / tracking +1% (капс: +5…+12%)

Мобильный: display 36–44, h1 32–36, h2 28, h3 22, body 16.
```

- Вес: заголовки 600–700 (не 800–900, кроме дисплейных гарнитур, задуманных такими), текст 400, акценты 500–600. Светлые начертания (300) в тексте — FAIL по читаемости.
- Капс: трекинг +5…+12% (Butterick); строчный текст трекинга не требует. Крупные заголовки — слегка отрицательный трекинг по глазу (Material: −0.2sp на 57sp), не «−3% всегда».
- Абзацы: интервал 50–100% кегля **или** красная строка — не оба.
- Выравнивание: текст и заголовки по левому краю. Центрирование — только короткие заголовки ≤ 2 строк и подписи под ними. Центрированный абзац из 4 строк — FAIL.
- Ширина текстового блока на десктопе: 560–720px при 16–18px.
- Числа в таблицах/тарифах — табличные цифры (tnum) и одна ширина колонок.
- Висячие предлоги и однобуквенные слова в конце строки заголовка — переносить (неразрывный пробел).
- Кавычки «ёлочки», тире «—», не дефис. Тире в каждом втором предложении — примета сгенерированного текста; одно на абзац.

## Как проверить себя

1. Смотрю на секцию в масштабе 50%: читается ли иерархия без чтения слов?
2. Считаю гарнитуры: ≤ 2?
3. Считаю размеры в секции: ≤ 4 (display/h2/body/caption)?
4. Абзац ≤ 75 символов в строке?
5. Кириллица на заголовке — «Дж», «Ф», «Л», «б», «ы», «З» выглядят как родные, а не дорисованные?
6. Если шрифт из нижней части таблицы (не рекомендуется) — есть ли на это прямое требование брифа?
