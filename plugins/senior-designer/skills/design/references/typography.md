# Типографика: выбор и настройка

## Как выбирать гарнитуру (порядок)

1. **Что сказано в брифе и референсах** — выполняется буквально. Если клиент прислал шрифт или бренд-бук — используется он, без обсуждения.
2. **Характер ниши и аудитории** → таблица ниже. Шрифт несёт тон: один и тот же лендинг на Inter читается как «нейтральный SaaS», на Playfair — как «редакция/премиум», на Unbounded — как «молодой бренд».
3. **Кириллица обязательна.** Русский текст на шрифте с плохой кириллицей (кривые «Д», «Ж», «Л», «б») — брак, который заметит клиент. В списке ниже кириллица проверена.
4. **Технические требования:** переменный шрифт (один файл, все начертания), лицензия (Google Fonts = бесплатно для коммерческого использования), наличие начертаний 400/500/600/700 минимум.
5. Предложить арт-директору **2 пары**, а не одну: «вариант А (спокойнее) / вариант Б (характернее)», показать на реальном заголовке и абзаце.

## Пары по нишам (отправная точка, не догма)

| Ниша | Спокойный вариант | Характерный вариант | Чего избегать |
|---|---|---|---|
| Финтех / банк / инвестиции | Inter + IBM Plex Mono для цифр | Manrope (заголовки) + Inter | антиквы «под люкс», Unbounded, кислотные акценты |
| Автосервис / мойка / детейлинг | Golos Text | Geologica (заголовки) + Golos | Montserrat Black капсом + красный (клише 2017) |
| Снегоходы / outdoor / powersports | Manrope + Inter | Geologica или Unbounded (заголовки) + Golos | «гранж»-текстуры, Impact-подобные |
| B2B SaaS | Inter | Onest или Manrope | иллюстрации «Corporate Memphis» |
| Премиум / люкс | Playfair Display + Inter | Cormorant Garamond + Manrope | золото #D4AF37, тонкие курсивы в тексте |
| Клиника / медицина | Golos Text | Commissioner + Inter | холодный «госпитальный» синий как единственный цвет |
| Недвижимость | Playfair Display + Inter | Jost + Lora | «дорогие» градиенты, золото |
| Образование / edtech | Onest | Commissioner + Lora | детские рукописные |
| Ресторан / еда | Playfair Display | Cormorant + Golos | скриптовые «handmade» шрифты |
| Агентство / портфолио | Inter с крупным кеглем | Unbounded / Onest | три гарнитуры «для разнообразия» |

Правило: заголовочная гарнитура — ровно одна. Текстовая — ровно одна. Моно — только если на странице есть код или таблицы цифр.

## Настройка (значения по умолчанию, пока бриф не требует иного)

```
Шкала 1.25 от 16 (лендинг, десктоп):
display   64–80 / lh 1.0–1.05 / tracking −2%   (герой)
h1        48–56 / lh 1.1    / tracking −1.5%
h2        36–40 / lh 1.15   / tracking −1%
h3        24–28 / lh 1.25
lead      20    / lh 1.5
body      16–18 / lh 1.5–1.6
small     14    / lh 1.45
caption   12–13 / lh 1.4 / tracking +1% (капс: +6%)

Мобильный: display 36–44, h1 32–36, h2 28, h3 22, body 16.
```

- Вес: заголовки 600–700 (не 800–900, кроме дисплейных гарнитур, задуманных такими), текст 400, акценты 500–600. Светлые начертания (300) в тексте — FAIL по читаемости.
- Капс: трекинг +5…+12% (Butterick); строчный текст трекинга не требует. Крупные заголовки — слегка отрицательный трекинг по глазу (Material: −0.2sp на 57sp), не «−3% всегда».
- Абзацы: интервал 50–100% кегля **или** красная строка — не оба.
- Выравнивание: текст и заголовки по левому краю. Центрирование — только короткие заголовки ≤ 2 строк и подписи под ними. Центрированный абзац из 4 строк — FAIL.
- Ширина текстового блока на десктопе: 560–720px при 16–18px.
- Числа в таблицах/тарифах — табличные цифры (tnum) и одна ширина колонок.
- Висячие предлоги и однобуквенные слова в конце строки заголовка — переносить (неразрывный пробел).
- Кавычки «ёлочки», тире «—», не дефис.

## Как проверить себя

1. Смотрю на секцию в масштабе 50%: читается ли иерархия без чтения слов?
2. Считаю гарнитуры: ≤ 2?
3. Считаю размеры в секции: ≤ 4 (display/h2/body/caption)?
4. Абзац ≤ 75 символов в строке?
5. Кириллица на заголовке — нет ли кривых «Д», «Л», «З», «б»?
