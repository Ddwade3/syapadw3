# Анти-паттерны: что НЕ делать

Список из двух частей: (1) «AI-вид» — приёмы, по которым любой дизайнер узнаёт сгенерированный макет, и (2) устаревшие или вредные паттерны. Каждый пункт — WARN при проверке; три и более в одной секции — FAIL. Файл пополняется из `design-notes.md` проекта после каждой забракованной работы.

## 1. Приметы «AI-дизайна» (не использовать по умолчанию)

Если бриф или референсы прямо требуют один из этих приёмов — делать, это выбор клиента. Если ось свободна — не тратить её на шаблон.

- Кремовый/off-white фон (#F4F1EA-ish) + контрастная антиква в заголовке + терракотовый акцент (#D97757-ish).
- Чёрный/почти чёрный фон (#0B0B0B, #111) с одним кислотно-зелёным или алым акцентом.
- «Газетная» вёрстка: волосяные линии, нулевой радиус, плотные колонки — там, где контент не редакционный.
- **Набор SaaS-карточек:** контент нарезан на одинаковые скруглённые карточки с одним радиусом на всём и одной мягкой серой тенью `rgba(0,0,0,.1)` под каждой; градиентные «пятна» как декорация.
- Шаблонная «обвязка» независимо от темы: ALL-CAPS «eyebrow»-метка над **каждым** заголовком; строки через точку-разделитель `A · B · C`; метки вида `WORD — fragment`; моноширинный шрифт для мелких подписей; стрелка `→` в конце каждой ссылки и кнопки.
- Нумерация `01 / 02 / 03` там, где контент не является последовательностью шагов.
- Одно слово в заголовке курсивом/цветом/другой гарнитурой («Делаем *красиво*»).
- **Inter на всём** без других типографических решений; «набор вкусных бесплатных шрифтов» (Space Grotesk, Geist, Instrument Serif, Fraunces) как дефолт; антиква везде с неоправданным курсивом.
- Фиолетово-синий или индиго градиент в герое/кнопках/фоне; свечение за героем; градиентный текст; неоновые рамки.
- «Sparkle»-бейдж-пилюля над заголовком («✨ Новое»), eyebrow с точкой в начале и линией в конце; пульсирующие точки у меток.
- Карточка в карточке в карточке; одинаковые квадратики с иконками Lucide на каждой карточке; цветная полоса только слева у карточки; одинаковый радиус 16 везде.
- «Стеклянный» навбар поверх всего; бенто из шести акцентных цветов; изумрудный как «следующий безопасный акцент»; тёплый янтарный акцент на серьёзном финтехе.
- Фейковые дашборды, метрики, логотипы и отзывы «для вида».
- В копирайте: тире в каждом втором предложении, «Build the future»-заголовки без конкретики.
- Кнопки-«пилюли» (полное скругление) везде, в том числе на полях и карточках, — не доказанная примета, но дефолт; радиус выбирается один раз как система.
- «Большое число + маленькая подпись + градиент» как единственный приём героя.
- Fade-and-slide-up на каждой секции и hover-подъём каждой карточки (в описании прототипа).
- Три иконки в кружочках + заголовок + две строки — «ряд преимуществ» по умолчанию.
- Аватарки-кружки в ряд «нам доверяют 10 000+» без реальных логотипов/людей.
- Иллюстрации в стиле «Corporate Memphis» (фиолетовые человечки с длинными руками).
- Бесконечная бегущая строка логотипов как первый же элемент после героя.
- Сгенерированные картинки с «глянцем»: пластиковые 3D-блобы, абстрактные стеклянные фигуры, лица с лишними пальцами. Генерация из ChatGPT проходит ту же проверку, что и макет.

## 2. Устаревшие и вредные паттерны

| Паттерн | Почему плохо | Что вместо |
|---|---|---|
| Карусель/слайдер в герое | Baymard: у 46% сайтов с каруселью на главной есть проблемы юзабилити; NN/g: пользователи пролистывают и не видят следующие слайды; автопрокрутка на мобильном — нельзя | один сильный герой с одной целью; статичные секции работают не хуже |
| Стоковое фото «люди жмут руки» | NN/g (айтрекинг): стоковых людей игнорируют, смотрят на информативные картинки; сток вводит в заблуждение о том, чем занимается компания | продукт, реальная съёмка, интерфейс, типографика |
| Параллакс и scroll-jacking | NN/g: тормозит, контент пропускается, укачивает; scroll-jacking — пользователи думают, что сайт сломан; WCAG 2.3.3 | одна оркестрованная анимация при загрузке, остальное — на действие; никогда не менять направление прокрутки |
| Гамбургер-меню на десктопе | NN/g (179 участников): скрытой навигацией пользуются в 27% случаев против 48% видимой, задачи на десктопе дольше на ≥39%, находимость −20% | 4–6 пунктов видимой навигации + CTA; на мобильном при ≤4 ссылках тоже показывать |
| Автовоспроизведение видео со звуком | NN/g: первым делом выключают или ставят на паузу; WCAG 1.4.2; Chrome блокирует звук без взаимодействия | без звука, с кнопкой, или постер |
| Всё по центру (абзацы, списки, формы) | теряется ось чтения, рваные края | левый край; центр только для коротких заголовков |
| Тяжёлые тени, «длинные тени», скевоморфные кнопки | 2013–2016 | тонкая граница 1px или мягкая тень 0 1 2 / 0 8 24 с низкой альфой |
| Градиентные «блобы» 2018–2020 | дата на лбу | плоский цвет, фотография, узор, сетка |
| Текст поверх фото без подложки | контраст плавает, нечитаемо | затемнение 40–60%, подложка, текст рядом с фото |
| Форма в две-три колонки | ошибки, пропуски полей | одна колонка |
| Плейсхолдер вместо подписи | исчезает, забывается | подпись над полем |
| «Отправить» / «ОК» на кнопке | не говорит, что произойдёт | глагол результата |
| Фейковые отзывы с фотостоков | клиент и пользователи узнают; в США с 2024 г. запрещены правилом FTC (штрафы), в ЕС — недобросовестная практика | реальные (или честно обозначенные примеры в макете) |
| Cookie-стена на весь экран | блокирует контент; в ЕС (EDPB 05/2020) согласие под cookie-стеной не считается добровольным | компактная плашка |
| Незапрошенные попапы (рассылка, чат, модалки) | NN/g: оверлеи только по действию пользователя или по закону | встроенные блоки, липкая узкая полоса |
| Скролл-анимация «всё въезжает снизу» на каждой секции, hover-подъём каждой карточки | NN/g: движущееся принимают за рекламу; типовая примета генерации | одна анимация при загрузке; движение в ответ на действие |
| Серый #999 для второстепенного текста на белом | 2.8:1 — не читается | ≥ #767676 (4.5:1) |
| Иконки из трёх разных наборов | разная толщина линии, разная сетка | один набор, один стиль (outline **или** filled) |
| «Воздух ради воздуха»: 300px пустоты между слабо связанными блоками | теряется связь, лишний скролл | отступы по закону близости из rules.md |
| Текст в каждом свободном месте, 3 абзаца в карточке | перегруз, повтор | один тезис на элемент; остальное — в раскрывающийся блок или на отдельную страницу |
| Дублирование информации (та же мысль в герое, в фичах и в CTA) | читатель решает, что сайт пустой | каждый факт звучит один раз, в самом сильном месте |
| Бенто-сетка «потому что модно» | плитки без логики, разные масштабы контента | бенто только когда есть 5–8 разнородных фактов одного веса |
| Стеклянный морфизм на светлом фоне | теряется контраст и граница | только на насыщенном фоне и только для одного слоя |

## 3. Слова и копирайт

- «Инновационный», «уникальный», «лучший», «решения под ключ», «индивидуальный подход» — пустые слова, заменить фактом.
- Заголовок героя отвечает на вопрос «что это и зачем мне», а не «Добро пожаловать».
- Не писать от лица системы: «Вы ввели неверные данные» → «Проверьте пароль».
- Одинаковые существительные в трёх соседних заголовках — перегруз; разнообразить структуру.
